<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Signed, notarized bundle → runtime writes | Any write inside the .app breaks its seal and Gatekeeper's verdict |
| Bundle resources → per-user engine copy | The copy is what the port executes from |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-14 | Tampering | writes into the signed bundle | high | mitigate | Frozen NXNATIVE is the user-folder copy; bytecode off; Engine tests assert the read-only resource listing is unchanged; plan 01-06 smoke re-checks `codesign --verify --deep --strict` after a run |
| T-1-15 | Tampering | engine copy in the user folder edited by another same-user process | low | accept | Same-user trust boundary; a new bundle version gets a fresh copy under a new id |
| T-1-16 | Tampering | a half-made engine copy used by a racing process | medium | mitigate | Copy into <id>.tmp-<pid>, then one os.rename; losers delete their temp (Engine.test_concurrent_first_start) |
| T-1-SC | Tampering | package installs | low | accept | Stdlib only; no installs in this plan |
</threat_model>
